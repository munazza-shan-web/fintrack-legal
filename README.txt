## 🚀 Deployment

This website is hosted using **GitHub Pages**.

To deploy:

1. Open repository Settings.
2. Navigate to Pages.
3. Select **Deploy from a branch**.
4. Choose the `main` branch.
5. Select the `/ (root)` folder.
6. Click Save.
