FINTRACK LEGAL WEBSITE — GITHUB PAGES SETUP

Files:
- index.html
- privacy-policy.html
- terms-and-conditions.html

1. Create a public GitHub repository named: fintrack-legal
2. Upload all three HTML files to the repository root (not inside another folder).
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish the site.
